# 💰 Expense Tracker

A simple and lightweight **Expense Tracker** built with HTML, CSS, and JavaScript. It allows users to record income and expenses, view their current balance, manage transactions, and store transaction data directly in the browser.

## ✨ Features

- 💰 Track income and expenses
- 📊 View total balance
- 📈 View total income
- 📉 View total expenses
- ➕ Add new transactions
- 🗑️ Delete transactions
- 💾 Automatically save transactions using browser Local Storage
- 🔄 Automatically update the balance and financial summary
- 📋 Display transactions in a clean list
- 💵 Format amounts as US Dollars (USD)
- 📱 Responsive design
- 🎨 Modern green-themed interface
- ⚡ Lightweight and runs entirely in the browser

## 🛠️ Built With

This project is built using standard front-end web technologies.

- **HTML5** – Application structure
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Transaction management and calculations
- **Local Storage API** – Persistent transaction storage
- **Intl.NumberFormat API** – Currency formatting
- **Google Fonts – Poppins** – Typography
